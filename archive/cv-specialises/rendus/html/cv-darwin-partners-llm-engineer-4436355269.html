no-excuse — Recrutement responsable assisté par IA

Juillet 2026 · prototype open source déployé

  • Conçoit un pipeline en deux étapes — filtrage puis scoring — avec traitements asynchrones séparés, résultats structurés et note détaillée pour chaque critère professionnel annoncé.
  • Implémente une architecture multi-fournisseur via Laravel AI SDK, avec choix distinct des modèles de filtrage et de scoring, validation stricte des réponses et reprise des traitements en échec.
  • Pseudonymise localement les CV avant tout appel distant ; bloque l'analyse si cette étape échoue et chiffre la copie de travail.
  • Maintient la décision finale côté recruteur : un rejet proposé doit être confirmé et le classement ne sélectionne jamais automatiquement un candidat.

Preuves : démo · code source MIT

Stack : Laravel 13 · Vue 3 · TypeScript · PostgreSQL · Redis · Python/FastAPI · Docker · GitHub Actions
